02 / 工作方式

从一条消息，到有出处的产品线索。

  1. 01 / 聚合

    接入公开信源

    覆盖 OpenAI、Google、Microsoft 等官方博客及其他公开来源；这些信源不代表厂商合作或背书。

  2. 02 / 筛选

    按问题与来源排序

    关注模型能力、AI 产品与 Agent 等主题，优先一手证据；不按 RSS 或热榜形式机械决定优先级。

  3. 03 / 分析

    绑定原文，标明不确定性

    将标题、结论与来源链接对应；只有线索入口的消息标为待核验，不当作已证实事实。

  4. 04 / 交付

    形成每日邮件简报

    输出与产品判断相关的简报；AI 分析不可用时，降级为附有效来源链接的采集简报，不编造结论。
