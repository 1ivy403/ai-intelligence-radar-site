# AIPM Radar 展示页

这是面向 AI 产品经理的情报项目展示页：介绍模型选型、竞品判断和产品规划中的信息问题，并展示 2026-09-17 全天汇总邮件的完整脱敏简报，包括五条重点情报与今日观察。

本仓库仅存放用于公开展示的脱敏历史简报，不包含私有运行系统或收发件信息。简报分析与行动建议由 AI 自动生成，原始来源可追溯，但不构成独立事实核验。网站不收集邮箱，也尚未开放订阅。

项目基于 [TrendRadar](https://github.com/sansan0/TrendRadar) 面向 AI 产品经理的信息获取场景进行垂直化二次开发。TrendRadar 是独立的上游开源项目，采用 [GPL-3.0](https://github.com/sansan0/TrendRadar/blob/master/LICENSE) 许可证；本展示页不代表上游或新闻来源厂商的合作与背书。简报中的 NVIDIA 原文配图标有来源，五条情报均附原始链接。

本地预览：在仓库目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000/`。内容检查：运行 `npm test`。
